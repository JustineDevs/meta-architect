---
title: Support and contribution
description: Where to report a problem or improve the project.
---

For a reproducible problem, include:

- the Meta-Architect version;
- the host surface;
- the command that was run;
- the relevant `ma doctor` result;
- the smallest safe reproduction.

Open an issue in the [Meta-Architect repository](https://github.com/JustineDevs/meta-architect/issues).
Do not include API keys, private source code, or `.env` values in reports.
