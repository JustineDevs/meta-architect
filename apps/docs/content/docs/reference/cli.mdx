---
title: CLI reference
description: The commands most users need.
---

| Command | Purpose |
| --- | --- |
| `ma setup` | Detect hosts and create project state |
| `ma status` | Show current workflow state |
| `ma doctor` | Check setup, artifacts, and runtime health |
| `ma --version` | Show the installed version |
| `ma --help` | Show available commands |
| `ma --madmax --high` | Launch the configured high-autonomy runtime |

Commands that modify project files should be run from the project root.
