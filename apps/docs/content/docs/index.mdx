Meta-Architect adds a visible workflow around your AI coding agent. It helps the
agent inspect the project, make decisions, verify changes, and leave evidence
behind.

## Start here

| You want to | Start with | You will have |
| --- | --- | --- |
| Install it | [Getting started](/docs/getting-started) | A working project setup |
| Understand the workflow | [How it works](/docs/concepts/how-it-works) | A simple mental model |
| Use Maestro | [Autonomous work](/docs/guides/autonomous-work) | One goal that runs through the workflow |
| Connect another agent | [Agent hosts](/docs/guides/agent-hosts) | A host-specific setup |
| Find a command | [CLI reference](/docs/reference/cli) | The exact command and result |
| Verify a host or lane | [Conformance matrix](/docs/reference/conformance) | Explicit evidence requirements |

## The short version

```text
install -> setup -> state one goal -> Maestro chooses the next safe action
       -> execute -> verify -> record evidence
```

The repository `docs/` directory contains deeper engineering notes. This site
keeps the public path task-oriented and easy to scan.
