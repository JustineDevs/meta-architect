# Accessibility and usability dossier

`$vibe` uses WCAG 2.2 as the default accessibility reference for user-facing
web, documentation, plugin, and CLI-adjacent surfaces.

## Default review

Walk the complete journey through setup, first success, errors, waiting, retry,
and recovery. Map material barriers to the applicable WCAG success criterion,
then verify with a combination of automated checks, keyboard interaction,
screen-reader or accessibility-tree review, contrast checks, and a human task
walkthrough. WCAG conformance does not by itself guarantee good usability, so
the lane must still address terminology, feedback, discoverability, and
operator confidence.

## Reference source

The pinned reference is [Web Content Accessibility Guidelines (WCAG) 2.2](https://www.w3.org/TR/WCAG22/),
commit `71c891a49f50f58766597a8980f6b2d2eedd5679` through
`https://gitmcp.io/w3c/wcag`. Credit belongs to W3C and the WCAG Working Group.
Confirm the exact success-criterion text from the pinned source before recording
an evidence receipt.
