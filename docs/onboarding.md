# Onboarding

This file is the short operator entrypoint for someone who just opened the repo and needs to understand how not to misuse it.

## First reading order

1. `README.md`
2. `docs/getting-started.md`
3. `docs/release-spec.md`
4. `docs/skills.md`
5. `docs/skills-publishing.md`

## First commands

```bash
npm install
npm link
ma setup
ma
```

## First safety rules

- Do not commit runtime `.meta-architect` state.
- Do not bypass gates by editing status files manually.
- Do not assume a release channel succeeded without evidence.
- Do not treat fallback MCP docs mode as normal verified evidence.
